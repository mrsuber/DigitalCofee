# Audio Files Directory

This directory contains the binaural beats audio files for the Digital Coffee app.

## Structure
```
audio/
├── alpha/          # Alpha wave tracks (8-12 Hz)
│   ├── morning-creative-flow.mp3
│   ├── deep-meditation.mp3
│   ├── creative-breakthrough.mp3
│   └── relaxed-focus.mp3
└── beta/           # Beta wave tracks (12-30 Hz)
    ├── peak-performance.mp3
    ├── study-power.mp3
    ├── laser-focus.mp3
    └── energy-boost.mp3
```

## Getting Audio Files

### Free Sources (Royalty-Free):

1. **Pixabay** - https://pixabay.com/music/search/binaural%20beats/
   - Completely free, royalty-free
   - No attribution required
   - Various binaural beats tracks

2. **ZenMix** - https://zenmix.io/binaural-beat-generator
   - Free binaural beat generator
   - Create custom frequencies
   - Download as MP3

3. **Internet Archive** - https://archive.org
   - Search for "binaural beats"
   - Free to download and use

### How to Add Files:

1. Download binaural beats MP3 files from the sources above
2. Rename them to match the filenames in this directory
3. Place them in the appropriate folder (alpha/ or beta/)
4. Restart the backend server

### File Requirements:

- **Format**: MP3
- **Bitrate**: 128kbps or higher recommended
- **Duration**: Can vary (10-60 minutes)
- **Frequency Ranges**:
  - Alpha: 8-12 Hz
  - Beta: 12-30 Hz
